生存战争（Survivalcraft）服务器可视化管理面板 —— 由 **JIILNetTechStudio** 开发与维护。

开箱即用的能力：创建实例 → 启动服务端 → 看控制台 → 管玩家和背包 → 看世界地图 → 传模组改配置 → 配权限和定时任务，全部在浏览器里完成，不需要装客户端。

## 特色功能

1. **游戏内插件深度集成**
   面板随实例自动安装游戏内插件（只覆盖 DLL，不动你的配置）。在线玩家、背包、世界数据、TPS 都来自插件实时上报；未装插件时面板会明确提示并可一键安装，不会给你一堆空页面。

2. **背包可视化编辑器**
   生存背包与创造背包（含衣物槽）按槽位图标化展示与编辑，数量与槽位规则有校验（衣物槽与背包不能互换），保存即写回实例，支持批量清空。

3. **世界地图渲染 + 玩家轨迹**
   直接解析存档 Region 文件生成俯视地图 PNG，叠加玩家标记；点标记可查看行走轨迹、居中或传送，不需要额外开服工具。

4. **多实例 + 容器目录迁移**
   一个面板管理多个实例；实例目录可整体切换到其他磁盘，单实例迁移带锁保护（停止 → 复制 → 删旧目录 → 更新记录），避免重复复制或误删。

5. **事件驱动的定时任务**
   除了 cron 表达式，还能监听实例启动 / 停止 / 崩溃、TPS 低于阈值、文件变化等事件执行脚本；另有「AI 任务」，到点由 AI 无人值守执行提示词。支持 JSON 导入导出、单次超时、提权运行、触发冷却。

6. **AI 助手（带审批与审计）**
   多模型接入，工具调用按风险分级：危险命令直接拒绝，未知操作走审批；每轮改动可回滚，全程留审计，AI 使用独立工作区，不碰实例目录。

7. **SCKey 统一登录**
   玩家进服前经 SCKey 验证，有效拦截小号、盗版与恶意进服。面板提供三步懒人向导，绑定后自动写入实例配置，且只加必要字段、不改动已有配置。

8. **通知守护**
   实例崩溃、守护进程失联、CPU / 内存 / 磁盘超阈值可推送邮箱（SMTP）或 Webhook；即使不配通知，异常也会记入审计日志与面板日志，并在你下次打开页面时弹出。

9. **整包自动更新**
   面板、守护进程、更新器三件套一起升级：下载校验完成后写入待更新标记，守护进程在**所有实例停止**时才拉起更新器替换二进制并重启面板，不打断在线玩家。

10. **细粒度权限**
    用户组 + 菜单级权限 + 实例级授权（控制台、文件、备份、资源限制、实例设置分开授权）；文件访问分「受限 / 全盘只读 / 全盘读写」三档，普通用户只能看到分配给自己的实例。

11. **三种配置编辑方式**
    打开 `.json` 等配置文件可选快速编辑（键值表单）、可视化编辑（树形）、源码编辑；自动识别 GBK / UTF-8，避免中文乱码。

12. **终端与快捷命令**
    面板宿主机上的真实 shell 多会话（Windows PowerShell / CMD，Linux bash），面板运行期间会话常驻、可随时切回；控制台可预设快捷命令一键下发。

13. **资源限制与性能曲线**
    按实例设置 CPU / 内存阈值与超限处理策略，仪表盘展示实时 TPS 与性能曲线，低配机器也能稳住。

14. **三层备份体系**
    世界备份、整实例目录 zip 总备份（可自定义备份目录）、实例克隆，误操作后可快速回到正常状态。

15. **独立维护工具（scweb-manage）**
    随安装脚本落地、全机只保留一份：Windows 在桌面与开始菜单创建快捷方式，Linux 注册为 `~/.local/bin/scweb-manage` 命令。菜单式操作：启动面板、查看自启动状态、修复安装（替换程序文件但保留配置与数据）、全新安装（新增实例，不影响已有）、卸载、检查更新（支持指定版本并校验、预览版额外提示）、设置别名。多面板时先列出各实例的目录 / 版本 / 安装时间让你选择。

16. **统一安装清单与 HTTPS**
    安装脚本、面板、维护工具共用一份安装清单（Windows 注册表 / Linux 配置文件），面板更新后自动同步版本；面板内可查看全部面板实例并设置别名。设置页可直接填写 PEM 证书与私钥并绑定域名，证书缺失、过期或域名不匹配时面板启动自动降级为 HTTP，不会因证书问题打不开。

## 一键安装

Windows（PowerShell）：

```powershell
irm https://gitee.com/JIILStudio/jiilsc-web-manger/raw/master/install.ps1 | iex
```

Linux：

```bash
curl -fsSL https://gitee.com/JIILStudio/jiilsc-web-manger/raw/master/install.sh | bash
```

安装脚本会自动识别本机 CPU 架构并选择对应安装包，安装过程中可选择目录（默认 / 手动输入 / 文件管理器选择），完成后自动启动守护进程与面板，并输出访问地址与初始管理员账号。

安装完成后会同时落地维护工具 `scweb-manage`：Windows 位于 `%LOCALAPPDATA%\SCWebManager\scweb-manage.exe` 并创建桌面与开始菜单快捷方式；Linux 位于 `~/.local/bin/scweb-manage`（若该目录不在 PATH 中会给出配置提示）。

安装参数（可选）：

| 参数 | 说明 |
| --- | --- |
| `-1 <目录>` | 指定安装目录 |
| `-2 <版本>` | 指定版本（`latest` 或具体版本号） |
| `-f` | 静默安装，使用默认值 |
| `-json` | 仅输出一行 JSON 结果 |

## 手动安装

1. 打开 [发行版](https://gitee.com/JIILStudio/jiilsc-web-manger/releases) 页面，按你的平台与架构下载对应安装包；
2. 解压到任意目录（重复安装时保留已有 `data` 目录即可保留配置与数据）；
3. 先运行 `scweb-daemon`（Windows 为 `scweb-daemon.exe -dir <目录>`），再运行 `scweb-panel`；
4. 浏览器访问 `http://127.0.0.1:18233`，使用启动日志中给出的初始账号登录。

## 文件校验

发行版附带的 `SHA256SUMS` 是各安装包的 SHA-256 校验值，**不是程序，下载后无需运行**。校验方法：

```powershell
# Windows
Get-FileHash .\scweb-1.5.9-windows-amd64.zip -Algorithm SHA256
```

```bash
# Linux / macOS
sha256sum -c SHA256SUMS
```

输出与清单一致即可；不一致说明下载不完整或被篡改，请重新下载。安装脚本会自动校验，手动安装时建议核对一次。

## 自动更新

面板内置更新检查：登录后自动检查，也可在「设置 → 更新管理」手动检查。更新为整包更新，按当前平台与架构选择安装包，下载校验完成后由守护进程在实例全部停止时替换三个程序并重启面板。
